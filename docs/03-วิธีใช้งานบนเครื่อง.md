# ตั้งค่าครั้งแรกบน Galaxy S25+

---

## เตรียมโฟลเดอร์รูปก่อน (แนะนำมาก)

วิธีนี้ทำให้เพิ่มรูปทีหลังง่ายที่สุด และไม่ต้องกลับมาเลือกไฟล์ทีละใบ

1. บนเครื่อง เปิด **My Files → ที่จัดเก็บภายใน → DCIM**
2. สร้างโฟลเดอร์ชื่อ `Wallpapers`
3. โยนรูป 4K และวิดีโอที่อยากใช้ลงไป

ต่อไปเวลาจะเพิ่มรูป แค่ก๊อปไฟล์ลงโฟลเดอร์นี้ แล้วเข้าแอพกด **สแกนหาไฟล์ใหม่** เท่านั้น

---

## ขั้นที่ 1 — เพิ่มสื่อเข้าคลัง

เปิดแอพ **WallFlow 4K** แท็บ **คลังภาพ**

**แบบเชื่อมโฟลเดอร์ (แนะนำ)**
กด **โฟลเดอร์** → เลือก `DCIM/Wallpapers` → **อนุญาต** วิธีนี้ได้ทั้งรูปและวิดีโอในครั้งเดียว

**แบบเลือกไฟล์**
มีสองปุ่มแยกกันคือ **รูป** กับ **วิดีโอ** เลือกได้หลายไฟล์พร้อมกัน

> ปุ่มแยกกันโดยตั้งใจ ตัวเลือกไฟล์ของ One UI กรองไม่แม่นเวลาส่งหลายชนิดไปพร้อมกัน จึงมักโชว์แค่รูปแล้วซ่อนวิดีโอ การส่งชนิดเดียวไปตรงๆ แก้ปัญหานี้
>
> ถ้ากด **วิดีโอ** แล้วยังไม่เห็นไฟล์ แปลว่าหน้าต่างเปิดค้างอยู่ที่แท็บ **ล่าสุด** ซึ่งบางทีไม่ลิสต์วิดีโอ ให้กดเมนู **☰** มุมบนซ้าย แล้วเลือก **ที่จัดเก็บภายใน → DCIM** จะเห็นไฟล์ครบ

> ไฟล์ไม่ได้ถูกคัดลอก แอพจำแค่ว่าไฟล์อยู่ที่ไหน ถ้าคุณลบไฟล์ต้นฉบับทีหลัง รายการนั้นจะเปิดไม่ได้ กด **ตรวจไฟล์เสีย** ในหน้าตั้งค่าเพื่อล้างออก

---

## ขั้นที่ 2 — เปิดใช้ Live Wallpaper (ทำครั้งเดียวตลอดไป)

นี่คือขั้นที่ทำให้ทะลุข้อจำกัดของ One UI

1. กด **เปิดใช้ Live Wallpaper (ทำครั้งเดียว)**
2. หน้าพรีวิวของระบบจะเด้งขึ้นมา
3. กด **ตั้งเป็นวอลเปเปอร์**
4. ระบบจะถามว่าจะลงที่ไหน มีสามตัวเลือก ให้เลือก **หน้าจอหลักและหน้าจอล็อก** (ยืนยันแล้วว่ามีจริงบน S25+ Android 17) วิดีโอจะเล่นทั้งสองจอ

ตั้งเสร็จแล้ว **ไม่ต้องกลับมาทำซ้ำอีก** จากนี้คุณเพิ่มรูปกี่ร้อยใบก็ได้ แอพจะสลับเนื้อหาข้างหลัง Live Wallpaper ช่องเดิมเอง

> สวิตช์ **มิเรอร์ไปจอล็อก** ปิดไว้เป็นค่าเริ่มต้น และควรปิดไว้เมื่อ live wallpaper ลงทั้งสองจอได้แล้ว เพราะการมิเรอร์คือการเขียนภาพนิ่งลงจอล็อก ซึ่งจะถอด live wallpaper ออกจากจอล็อกทันที เปิดเฉพาะกับเครื่องที่ลงได้แค่หน้าจอหลักเท่านั้น
>
> ถ้าเผลอเปิดไว้แล้วจอล็อกกลายเป็นภาพนิ่ง กดปุ่ม **คืนค่าจอล็อกเป็นค่าเริ่มต้น** ที่ท้ายหน้าตั้งค่า จอล็อกจะกลับมาใช้ live wallpaper ทันที

---

## ขั้นที่ 3 — เลือกว่าให้เปลี่ยนรูปเมื่อไหร่

แท็บ **ตั้งค่า → เปลี่ยนรูปเมื่อไหร่**

| โหมด | ทำงานยังไง | กินแบตไหม |
|---|---|---|
| **ปลดล็อก** (ค่าเริ่มต้น) | เปลี่ยนทุกครั้งที่หน้าจอหลักปรากฏหลังปลดล็อก | แทบไม่กิน ใช้จังหวะที่ engine ตื่นอยู่แล้ว |
| **ตามเวลา** | ตั้งได้ 1 นาที – 12 ชั่วโมง | น้อย ใช้ alarm แบบไม่เป๊ะที่ระบบจัดคิวได้ |
| **แตะสองครั้ง** | แตะสองครั้งบนพื้นที่ว่างของหน้าจอหลัก | ไม่กินเลย |
| **ปิด** | เปลี่ยนเมื่อคุณสั่งเองในแอพเท่านั้น | ไม่กินเลย |

เปิด **สุ่มลำดับ** ได้ถ้าไม่อยากให้วนตามลำดับเดิม

---

## ขั้นที่ 4 — เลือกว่าจะให้สองจอเหมือนหรือต่างกัน

แท็บ **ตั้งค่า → จอที่ควบคุม**

**เปิด "ตั้งหน้าหลักและจอล็อกพร้อมกัน"** (ค่าเริ่มต้น)
รูปเดียวกันทั้งสองจอ เปลี่ยนพร้อมกันในคำสั่งระบบครั้งเดียว ไม่มีจังหวะเหลื่อม

**ปิดสวิตช์นี้** ถ้าอยากให้คนละชุด

⚠️ **ปิดสวิตช์อย่างเดียวยังไม่พอ** รูปทุกใบที่เพิ่มเข้ามาจะถูกแท็ก **ทั้งสองจอ** เป็นค่าเริ่มต้น ถ้าไม่แท็กใหม่ คิวของสองจอก็ยังเป็นชุดเดียวกัน คุณจึงเห็นรูปเดิมทั้งสองจอเหมือนตอนเปิดสวิตช์

ต้องกลับไปแท็บคลังภาพ **กดค้าง** ที่รูป เลือกหลายรูปได้ แล้วกดปุ่มด้านล่าง

- **หน้าหลัก** → รูปนี้ขึ้นเฉพาะหน้าจอหลัก (ป้าย H)
- **ล็อก** → ขึ้นเฉพาะจอล็อก (ป้าย L)
- **ทั้งคู่** → ขึ้นทั้งสองจอ (ป้าย H L)

หน้า **ตั้งค่า → จอที่ควบคุม** จะบอกจำนวนที่แท็กไว้แต่ละแบบ และเตือนเป็นสีแดงถ้ายังไม่มีรูปที่แท็กให้จอล็อกโดยเฉพาะ

นอกจากนี้ ถ้าคิวของสองจอมีรูปซ้อนกันอยู่ แอพจะเลื่อนคิวจอล็อกให้พ้นรูปที่หน้าจอหลักใช้อยู่โดยอัตโนมัติ สองจอจึงไม่ขึ้นรูปเดียวกันเวลาปิดโหมดซิงก์

เมื่อ live wallpaper ลงทั้งสองจอ แต่ละจอจะมี engine ของตัวเอง และ engine จอล็อกจะอ่านคิวจอล็อกโดยตรง ส่วนการเลื่อนคิวทำโดย engine จอหลักเท่านั้น การเปิดดูจอล็อกจึงไม่ทำให้รูปเปลี่ยนเอง

---

## ขั้นที่ 5 — ตรวจว่านาฬิกาปรับสีตามรูป

1. ให้แน่ใจว่า **ตั้งค่า → ภาพและนาฬิกา → นาฬิกาปรับสีตามรูป** เปิดอยู่
2. กด **รูปถัดไป** ในแท็บคลังภาพ
3. กดปุ่ม Power ปิดจอ แล้วเปิดดูจอล็อก

นาฬิกาควรเปลี่ยนสีตามโทนของรูป ถ้ายังไม่เปลี่ยน

- ลองสลับระหว่างรูปสว่างจัดกับรูปมืดจัด ความต่างจะเห็นชัดกว่า
- เช็กว่า **ตั้งค่า (ของเครื่อง) → หน้าจอล็อก → สไตล์นาฬิกา** ไม่ได้ล็อกสีไว้ตายตัว ถ้าเลือกสีเองไว้ ระบบจะไม่ปรับตามภาพ

---

## ใช้งานประจำวัน

**เพิ่มรูปใหม่**
ก๊อปลง `DCIM/Wallpapers` → เปิดแอพ → **สแกนหาไฟล์ใหม่**

**อยากตั้งรูปใดรูปหนึ่งเดี๋ยวนี้**
แตะที่รูปนั้นในคลัง (แตะครั้งเดียว ไม่ใช่กดค้าง)

**อยากข้ามไปรูปถัดไป**
กด **รูปถัดไป** หรือถ้าใช้โหมดแตะสองครั้ง ก็แตะสองครั้งบนหน้าจอหลักได้เลย

**เอารูปออกจากคิว**
กดค้างที่รูป → กดไอคอนถังขยะ (ลบออกจากคลังเท่านั้น ไฟล์ต้นฉบับยังอยู่ครบ)

## ปรับจูนเรื่องแบตและความลื่น

ถ้าใช้วิดีโอเยอะแล้วรู้สึกว่าเครื่องร้อนหรือแบตลดไว

| ตั้งค่า | ทำอะไร |
|---|---|
| **หยุดวิดีโอเมื่อแบตต่ำกว่า N%** | ตั้งไว้ 20–30% วิดีโอจะหยุดเองเมื่อแบตเหลือน้อย |
| **ซูมช้าแบบ Ken Burns** | ปิดไว้ ช่วยได้มากเพราะไม่ต้องวาดภาพใหม่ตลอด |
| **คุณภาพภาพนิ่ง** | เลือก **สมดุล** บนจอ S25+ คมเท่ากับเต็มความละเอียด แต่ใช้แรมน้อยกว่าสี่เท่า |
| ใช้ภาพนิ่งแทนวิดีโอในคิวหลัก | วิดีโอเปลืองกว่าภาพนิ่งมาก ใช้เฉพาะไฟล์ที่ชอบจริงๆ |

วิดีโอจะ**หยุดเองอัตโนมัติ**อยู่แล้วเมื่อปิดหน้าจอ หรือเปิดแอพอื่นเต็มจอ ไม่ต้องตั้งอะไรเพิ่ม

---

## เช็กพื้นที่ที่แอพกิน

แท็บ **ตั้งค่า → พื้นที่จัดเก็บ**

- **แอพนี้ใช้** คือพื้นที่จริงที่แอพกิน = ไฟล์รายการ (หลักสิบ KB) + แคชรูปย่อ
- **ไฟล์ต้นฉบับที่อ้างอิง** คือขนาดรวมของรูปและวิดีโอในคลัง แสดงให้ดูเฉยๆ **ไม่ได้ถูกคัดลอก** ตัวเลขนี้ไม่ได้บวกเพิ่มในเครื่องคุณ

กด **ล้างรูปย่อ** ได้ทุกเมื่อ แอพจะสร้างใหม่เองตอนเปิดคลัง

---

## วิดีโอยังไม่เล่น ตรวจตามนี้

ไล่จากบนลงล่าง

1. **Live Wallpaper ถูกตั้งแล้วหรือยัง** วิดีโอเล่นได้เฉพาะผ่าน Live Wallpaper engine เท่านั้น ถ้ายังไม่ได้ตั้ง แอพจะใช้เฟรมนิ่งจากวิดีโอแทน ดูที่ **ตั้งค่า → สถานะระบบ** ต้องขึ้นว่า "Live Wallpaper: กำลังใช้งาน"
2. **ดูที่หน้าจอหลัก ไม่ใช่จอล็อก** One UI มักให้ Live Wallpaper ลงได้แค่หน้าจอหลัก จอล็อกจะเป็นภาพนิ่งตามที่อธิบายไว้ข้างบน
3. **วิดีโอถูกแท็กให้หน้าจอหลักหรือเปล่า** ต้องมีป้าย **H** บนรูปย่อ ถ้ามีแต่ **L** วิดีโอนั้นเข้าคิวจอล็อกซึ่งแสดงเป็นภาพนิ่ง
4. **แบตต่ำกว่าเกณฑ์ไหม** ค่าเริ่มต้นหยุดวิดีโอเมื่อแบตต่ำกว่า 20% ปรับได้ที่ **ตั้งค่า → แบตเตอรี่** เลื่อนไปที่ 0 เพื่อเล่นตลอด
5. **ไฟล์ถอดรหัสได้ไหม** ถ้าถอดรหัสไม่ได้ แอพจะแสดงเฟรมนิ่งแทนจอดำ และเขียนรหัสข้อผิดพลาดลง logcat

### อ่าน log ว่าเกิดอะไรขึ้น

ต่อสาย USB เปิด USB debugging แล้วรันบนคอม

```powershell
& "$env:LOCALAPPDATA\Android\Sdk\platform-tools\adb.exe" logcat -s WallFlowEngine
```

จากนั้นปลดล็อกเครื่องแล้วดูข้อความ

| ข้อความ | ความหมาย |
|---|---|
| `playback failed for ... : ERROR_CODE_DECODING_FORMAT_UNSUPPORTED` | เครื่องถอดรหัสโคเดกนี้ไม่ได้ ลองแปลงเป็น H.264 หรือ HEVC mp4 |
| `playback failed for ... : ERROR_CODE_IO_NO_PERMISSION` | สิทธิ์อ่านไฟล์หลุด ลบรายการแล้วเพิ่มใหม่ หรือใช้วิธีเชื่อมโฟลเดอร์แทน |
| `playback failed for ... : ERROR_CODE_IO_FILE_NOT_FOUND` | ไฟล์ต้นฉบับถูกลบหรือย้าย กด **ตรวจไฟล์เสีย** ในหน้าตั้งค่า |
| `surface not ready for ...` | จังหวะเริ่มต้นชนกัน ปลดล็อกอีกครั้งจะหาย |
| ไม่มีข้อความใดเลย | engine ไม่ได้ทำงาน แปลว่ายังไม่ได้ตั้ง Live Wallpaper |

## ถ้าอยากเลิกใช้

1. **ตั้งค่า (ของเครื่อง) → วอลเปเปอร์** เลือกวอลเปเปอร์อื่น Live Wallpaper ของเราจะหยุดทำงานทันที
2. ในแอพ กด **คืนค่าจอล็อกเป็นค่าเริ่มต้น** เพื่อให้จอล็อกกลับไปใช้ภาพเดียวกับหน้าจอหลัก
3. ถอนการติดตั้งแอพ ข้อมูลทั้งหมดของแอพหายไปพร้อมกัน **รูปและวิดีโอต้นฉบับของคุณไม่ถูกแตะต้อง**
